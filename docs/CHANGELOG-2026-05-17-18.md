# 开发日志 2026-05-17 ~ 2026-05-18

## 一、角色升级通道（USER → MERCHANT / RIDER）

### 问题
普通用户注册时角色硬编码为 `USER`，无法升级为商家或骑手。

### 修改

**后端 `UserController.java`**：新增 `PUT /user/upgrade-role` 接口
- 接收 `{ "role": "MERCHANT" }` 或 `{ "role": "RIDER" }`
- 校验只能升级为 MERCHANT 或 RIDER（拒绝 ADMIN）
- 更新数据库 `t_user.role`，签发新 JWT 返回

**前端 `user.js`**：新增 `upgradeRole(role)` API

**前端 `ProfileView.vue`**：USER 角色用户在个人中心看到"申请成为商家"和"申请成为骑手"按钮，成功后自动刷新 token 和用户信息

## 二、商家订单查询 bug 修复

### 问题
`OrderController.merchantList()` 将 `userId` 直接传给 `orderService.listMerchantOrders()`，但服务层按 `Order::getMerchantId` 查询，导致查不到订单。

### 修改

**后端 `OrderController.java`**：`merchantList` 改为从请求参数接收 `merchantId`

**前端 `DashboardView.vue`**：先获取 merchantId（通过 `getMyMerchant`），再用 merchantId 查询订单

**前端 `MerchantOrdersView.vue`**：同上，先获取 merchantId 再查询

## 三、商家详情页数据空白（MerchantCard ID 错误）

### 问题
商家列表点击进入详情页，商家信息和菜品都为空。

### 根因
`MerchantCard.vue` 用 `merchant.id` 生成链接，但搜索接口返回的是 `SearchMerchant` 对象，`id` 是 search_merchant 表的自增主键，不是真正的商家 ID。真正的商家 ID 在 `merchantId` 字段。详情页用错误的 ID 查询商家服务，返回 null。

### 修改
**前端 `MerchantCard.vue`**：链接改为 `/user/restaurants/${merchant.merchantId || merchant.id}`

---

## 四、商家列表不可见（滚动动画时序 bug）

### 问题
"发现美食"页面商家卡片在控制台有数据但页面不可见。

### 根因
`useScrollReveal` 在 `onMounted` 时设置 `IntersectionObserver`，但商家卡片是异步加载的——mount 时它们还不存在于 DOM 中，observer 永远观察不到它们，`visible` class 从未被添加。

### 修改

**`useScrollReveal.js` 改进**：返回 `{ reobserve }` 函数，异步加载内容后调用即可观察新出现的 `.reveal` 元素

**`RestaurantsView.vue`**：移除重复的 observer 代码，改用 `reobserve()`

**`RestaurantDetailView.vue`**：`fetchData` 完成后调用 `reobserve()`

---

## 五、GlassModal 点击无反应

### 问题
商家后台点击"添加菜品"按钮无反应，modal 不弹出。

### 根因
`GlassModal` 定义的 prop 是 `visible`，但调用方用的是 `v-model="showModal"`。Vue 3 的 `v-model` 默认绑定到 `modelValue` prop，而 modal 期望的是 `visible` prop——名字不匹配，modal 永远收不到 `true`。

### 修改
**`DishManageView.vue`** 和 **`AddressView.vue`**：`v-model="showModal"` → `v-model:visible="showModal"`

---

## 六、菜品保存后不显示

### 问题
商家后台保存了菜品，但菜品管理页面和用户端餐厅详情页都看不到菜品。

### 根因
创建菜品时前端不传 `status` 和 `stock`，后端也没设置默认值。MyBatis-Plus 把 NULL 显式写入数据库，覆盖了列的 `DEFAULT 1`。查询时 `WHERE status = 1` 过滤掉了 `status = NULL` 的记录。

### 修改
**后端 `DishController.java`**：`save()` 方法添加：
```java
if (dish.getStatus() == null) dish.setStatus(1);
if (dish.getStock() == null) dish.setStock(0);
```

**数据库**：批量更新已有记录 `UPDATE dish SET status=1 WHERE status IS NULL`
